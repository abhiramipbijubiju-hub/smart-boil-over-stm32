# smart-boil-over-stm32
# Smart Boil-Over Prevention System Using STM32

## About the Project
This project aims to simulate a smart system that monitors temperature and provides an alert when the temperature exceeds a predefined threshold.

## Objectives
- Monitor temperature using an STM32 microcontroller.
- Compare the temperature with a predefined threshold.
- Generate an alert when the threshold is exceeded.
- Demonstrate the system through simulation.

## Working Principle
1. A temperature value is provided to the STM32 system.
2. The system compares the value with the set threshold.
3. If the threshold is exceeded, an alert is generated.
4. The system demonstrates the proposed boil-over prevention logic.

## Tools and Technologies
- STM32 microcontroller
- Embedded C
- STM32CubeIDE / STM32 HAL
- Simulation tools (planned or used, depending on implementation)

## Project Status
Work in progress.

## Safety Note
This is a simulation and educational project. It has not been verified as a real-world appliance safety system.
